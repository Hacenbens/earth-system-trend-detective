# Challenge summary — Earth Science Data Trend Detective

Source: screenshots and judging files in this folder (transcribed 2026-11-13).

## What the app must do (hard requirements)
1. Decide on the data variable(s) for analysis.
2. Choose a region for the analysis.
3. Select the time period for the time series.
4. Create the time series and examine it — does it appear to have a trend?
5. Analyze the trend for significance.

=> The **product** must be a general tool where a user performs steps 1–5.
=> Our flagship investigation is a **showcase case study** run through that tool, not a replacement for it.

## Submission rules
- **Demo**: ≤ 7 slides (title + intro included) **or** ≤ 30 s video. Public link, no login/permission.
- **Project link**: public (website / GitHub / Drive…), no login.
- **Project details** must answer: what it does & how · benefits · intended impact · tools used · how it is creative · factors considered (energy, accessibility, cost…).
- **NASA data is mandatory** for Global Award eligibility — list every NASA dataset/resource used.
- No minors' names/voices/likenesses in submission.

## AI ("Super Intelligence") policy
- Generated content must **not** use/contain/modify NASA logos, flags, mission identifiers/branding.
- Clearly state where and how SI was used.
- SI images/videos: **visible watermark**. SI code/data/audio: acknowledge in text **and** metadata.
- Tracked in `docs/submission/si_usage.md`.

## Judging criteria (each scored /5)
| Criterion | What earns a 5 | Implication for us |
|---|---|---|
| Impact | Significant problem, large audience | Tie trends to people (food security, water, health) |
| Creativity | Novel approach, inventive execution | Multi-layer "detective" reasoning: trend → structure → mechanism |
| Validity | Scientifically sound, feasible, usable | Correct stats (seasonality, autocorrelation), honest uncertainty, working app |
| Relevance | NASA data is *core*, not decoration | NASA datasets must carry the trend analysis; non-NASA data only complements |
| Presentation | Clear, compelling story | 7 slides / 30 s — one strong story, one hero chart |
