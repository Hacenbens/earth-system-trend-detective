Trend tests: Mann–Kendall + Sen’s slope, with autocorrelation and start-year checks · Validation: NASA Giovanni, CHC CHIRPS v3 · Analysis code drafted with AI assistance (Claude Code)

Any user can pick a variable, a region and a period; the tool builds the time series and tests whether the trend is real. What makes it different is what comes next: it brings in independent atmospheric data, tests candidate physical mechanisms, and writes an evidence card for each one, with what supports it, what contradicts it and a confidence level. The first three layers are our scientific core; projection and solutions are clearly labelled as scenarios. Before trusting any number, we checked that our pipeline reproduces NASA’s Giovanni exactly and agrees with an independent gauge-based record.
